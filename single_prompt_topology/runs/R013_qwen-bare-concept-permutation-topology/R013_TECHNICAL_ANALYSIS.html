R013 provides the first clean six-permutation test of the project's central semantic-invariance hypothesis. It removes R012's synthesis question and assistant-prefix capture, keeps the same Qwen2.5-7B-Instruct model and topology machinery, and measures the same three concepts through a fixed newline anchor.

# R013 Semantic-Topology Analysis and Implications

## 1. What R013 was actually for

R012 established that higher-order semantic parents appeared more stable than exact token neighbourhoods and community partitions under one controlled order perturbation.

But R012 also exposed two confounds:

```text
semantic concepts
+
"What structure forms from" instruction
+
chat template
+
assistant-generation prefix
```

R013 therefore changed the experimental input while preserving the measured topology pipeline.

The concepts remained:

```text
A = electro pink
B = curvature density
C = Tokyo nightlife
```

All six possible permutations were measured:

```text
ABC
ACB
BAC
BCA
CAB
CBA
```

Each concept occupied one line and every prompt ended in the same single-token newline anchor.

The primary question became:

> Which higher-order semantic structures survive every ordering of the same concepts when no explicit synthesis instruction is supplied?

R013 does not prove that an order-invariant structure must exist. A null invariant core would also have been a valid result.

---

R013 used the same primary model as R012:

```text
revision a09a35458c702b33eeacc393d103063234e8bc28
BF16
Hugging Face Transformers
RTX 4090
```

The fixed capture anchor was:

```text
newline
token ID 198

```

All six raw inputs tokenised to exactly 12 tokens.

The anchor probe passed every required control:

```text

same capture rule
same token count
same State 00 vector
deterministic replay exact
all states finite
no response generation
```

State 00 was exactly identical across all six permutations.

Therefore every later difference arises only after contextual processing.

# 4. The strongest measured result: final-position dominance

The complete six-permutation design reveals a structural effect that R012 could not isolate.

Pairs sharing the same final concept are substantially more similar than pairs sharing the first concept, the middle concept, or no fixed position.

This occurs in:

```text
hidden-state cosine
token membership
edge structure
community partition
```

and it occurs at every post-context state.

Across S01-S28, the mean same-last comparison exceeded the mean of the other permutation relationships at:

```text
28 / 28 states for membership Jaccard
28 / 28 states for edge Jaccard
28 / 28 states for community ARI
```

The minimum same-last advantage at any state was still approximately:

```text
membership Jaccard +0.080
edge Jaccard       +0.102
community ARI      +0.006
```

The effect is strongest in the early and middle transformer.

For example, across S10-S18 on the positive side:

```text
same final concept:
membership ≈ 0.591
edge       ≈ 0.350
ARI        ≈ 0.423

no fixed position:
membership ≈ 0.386
edge       ≈ 0.169
ARI        ≈ 0.390
```

The negative side shows nearly the same membership and edge pattern.

This should be interpreted as a strong:

> final-position / anchor-proximity / recency association

rather than as an independently identified causal recency effect.

The final concept is immediately adjacent to the neutral anchor in a causal transformer. R013 removes the identity confound of measuring a concept token directly, but it does not remove sequential positional asymmetry.

The six-permutation design is valuable precisely because it lets the order-invariant core be identified despite this effect.

# 5. Order divergence has a clear trajectory

Cross-permutation invariance falls rapidly after contextual processing begins.

The six-way invariant core reaches its minimum around State 09.

Selected states show:

```text
                 positive                 negative
            token  edge              token  edge
S01         0.524  0.258             0.507  0.238
S09         0.126  0.019             0.134  0.022
S27         0.244  0.060             0.241  0.059
S28         0.445  0.175             0.428  0.164
```

Thus the representation passes through an order-sensitive bottleneck:

```text
COMMON ANCHOR
      ↓
rapid contextual differentiation
      ↓
MAXIMUM ORDER DIVERGENCE
around S09
      ↓
gradual reconvergence
      ↓
late transformer consolidation
      ↓
terminal recoding / convergence
```

The minimum average cross-permutation hidden-state cosine also occurs around State 09.

The most divergent measured pair is:

```text
BAC versus CAB
State 09
positive_head

membership Jaccard = 0.320201
edge Jaccard       = 0.125235
community ARI      = 0.312774
hidden cosine      = 0.791842
```

This is important because BAC and CAB both place electro pink in the middle. They differ by exchanging curvature density and Tokyo nightlife between first and final positions.

The maximum divergence therefore aligns strongly with the final-position effect.

# 6. Within-trajectory development is not the same as cross-permutation divergence

The largest within-permutation layer resets are:

```text
S00 → S01
context first enters the fixed anchor

S27 → S28
final normalisation recodes the last block representation
```

Inside the transformer, adjacent-state topology generally becomes more stable through depth.

Average adjacent-state membership Jaccard rises from roughly:

```text
S07 → S08   ≈ 0.428
S10 → S11   ≈ 0.495
S16 → S17   ≈ 0.599
S24 → S25   ≈ 0.674
S25 → S26   ≈ 0.698
```

Therefore the strong cross-permutation divergence around S09 is not simply a consequence of every trajectory becoming locally unstable.

The trajectories are becoming internally organised while simultaneously becoming different from one another.

This is consistent with:

```text
same concepts
+
different order
        ↓
different route through semantic organisation
```

rather than random representational noise.

The smallest defensible cross-permutation reconstruction is:

```text
            ↕

            ↕

NEGATIVE-ALIGNED CORE

SOCIAL / ACTIVITY / INSTITUTIONAL
            ↕
TRANSFORMATION / INTERACTION / DISTRIBUTION
            ↕
STRUCTURAL / CATEGORICAL ORGANISATION
```

The two sectors are measured independently and should not be drawn as though direct positive-negative graph edges were observed between them.

The broader conceptual intersection is therefore not best represented as a named aesthetic genre.

It is closer to:

> sensory and technical properties situated in an environment, organised through structural relations, alongside a social/activity field whose interactions and transformations form a distinct anti-aligned contextual structure.

This architecture survives permutation better than its exact vocabulary or community boundaries.

# 19. Does semantic invariance increase with abstraction?

R013 provides substantially stronger support for the R012 hypothesis, but with one qualification.

At the final transformer block, S27:

```text
only about 24% of unique tokens
are present in all six permutations

only about 6% of unique edges
are present in all six permutations
```

Yet all six trajectories still recover the broad parent families:

```text
sensory / material
place / environment
structural / measurement
social / activity
transformation / interaction
representation / operation
```

Therefore:

```text
EXACT TOKENS
highly order-sensitive

EXACT EDGES
more order-sensitive

COMMUNITY PARTITIONS
plastic

PARENT FAMILIES
substantially recoverable across all orders
```

This supports:

> semantic invariance increases with abstraction from measured tokens towards higher-order parent structure.

However, R013 does not justify the stronger universal claim that parent relations are always more invariant than parent identities.

The same broad relations recur across trajectories, but their state-local expression, parent absorption and community realisation remain order-sensitive.

The stronger conclusion should therefore be:

> parent relations are persistent candidates for invariant structure, but their invariance is trajectory-level rather than an exact 6/6 state-local identity.

# 20. State 28 is both a reset and a convergence

S27 is the final transformer-block output.

S28 is final normalisation.

The S27 → S28 transition is enormous within each permutation:

```text

average edge Jaccard       ≈ 0.009
```

Yet cross-permutation convergence increases sharply.

From S27 to S28:

```text

0.535 → 0.696

negative mean membership:
0.534 → 0.686

positive mean edge overlap:
0.297 → 0.464

negative mean edge overlap:
0.297 → 0.454
```

Six-way invariant membership also rises:

```text

24.4% → 44.5%

negative tokens:
24.1% → 42.8%

positive edges:
6.0% → 17.5%

negative edges:
5.9% → 16.4%
```

Thus final normalisation performs two things simultaneously in the fixed vocabulary basis:

```text

+
```

This is analytically important but must not be interpreted as another transformer reasoning step.

S27 remains the correct endpoint for transformer-computed semantic organisation.

S28 is useful as the output-facing recoding of that organisation.

> the R012 prompt-and-assistant-prefix configuration imposed a large shared representational scaffold that greatly reduced order sensitivity.

# 23. What R013 says about the neutral-anchor design

The neutral anchor succeeds at one task:

```text
the measured token itself
is no longer one of the concepts
```

State 00 equality proves that control.

But R013 also shows that a final causal anchor does not create positional symmetry.

The final concept remains nearest to the anchor and dominates structural similarity.

Therefore:

```text
NEUTRAL TOKEN ID
does not imply
POSITION-NEUTRAL REPRESENTATION
```

This is not a failure of R013.

It is a measured property of the design and of causal sequence processing.

The six-permutation invariant core should therefore be interpreted as:

> structure surviving a strong final-position bias,

which makes the surviving parent architecture more rather than less informative.

```text
repeatedly negative-aligned

cross-sector
```


GRD remains downstream of parent reconstruction.

# 25. Main methodological limitations

R013 is stronger than R012 but not final.

## One concept triplet

The parent architecture is demonstrated for:

```text
electro pink
curvature density
Tokyo nightlife
```

It is not yet evidence that the same developmental pattern generalises to arbitrary concept sets.

---

## Final-position and recency remain confounded

The last concept is also the concept nearest the anchor.

Therefore R013 establishes a strong final-position / proximity / recency association but cannot separate those mechanisms cleanly.

---

## Static input-embedding basis

Every state is interpreted relative to one fixed lexical geometry.

This is deliberate and useful for cross-layer comparability, but it is not the only possible coordinate basis.

---

## Louvain communities are geometric partitions

Community IDs are local and algorithm-dependent.

The semantic analysis therefore correctly treats them as evidence rather than final topics.

---

## Semantic parent reconstruction remains interpretive

Parent labels are constrained by community evidence, exclusions and cross-permutation comparison, but they are not directly measured model variables.

The report therefore distinguishes:

```text
measured topology
from
semantic reconstruction
```

throughout.

---

# 26. Recommended next experiment

The strongest next step is not to change the topology method.

It is to test whether the R013 findings replicate.

A subsequent run should use:

```text
same model
same neutral-anchor design
same six-permutation protocol
same topology machinery
different concept triplet
```

The first replication question should be:

> Does the same pattern recur: strong final-position dependence, minimum order invariance in the early-middle transformer, later reconvergence, and higher parent stability than exact token/edge stability?

Only after replication should the project add another major variable such as:

```text
base model versus instruct model
alternative embedding basis
alternative community algorithm
multi-position pooling
```

Changing the analytical machinery before testing replication would make it harder to determine whether R013 discovered a model-general structural phenomenon or a concept-set-specific pattern.

# Central conclusions

R013 supports five principal conclusions.

First:

> Concept order substantially changes hidden-state direction, selected vocabulary, graph edges and community organisation, with the strongest divergence around State 09.

Second:

> The final concept is the dominant positional determinant of similarity. Pairs sharing the same last concept are more similar than other permutation relationships at every post-context state.

Third:

> Exact topology is far less invariant than higher-order semantic structure. Even when only a small minority of exact edges survive all six permutations, the same broad sensory/material, place, structural, social, transformation and representation parents remain recoverable.

Fourth:

> Removing R012's synthesis shell materially changes the semantic architecture. Sensory/place/social parents remain robust, while transformation/composition and representation/information become more phase- and sector-dependent. This confirms that part of R012's higher-order structure was task-induced.

Fifth:
