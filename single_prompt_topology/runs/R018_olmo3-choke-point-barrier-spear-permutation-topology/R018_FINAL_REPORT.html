R018 — Final Report

OLMo 3 32B · choke point / collapsible barrier / spear · six prompt permutations · completed semantic reconstruction

Final result. R018 does not recover one fixed literal map that survives every prompt order. Instead, prompt order strongly conditions the early and middle representations, especially through the concept placed last, while the six trajectories later reconverge onto a shared higher-order topology organised around constraint / requirement, structural configuration, dynamic path geometry, and collapse / adjustment.

1. Objective

R018 tests whether a semantic structure can reconstitute across all six permutations of the same three concepts rather than merely reflecting their literal order. The experiment therefore separates two questions:

  • How strongly does order perturb the measured topology?
  • What semantic structure, if any, survives or re-emerges across all six orderings?

10. Control interpretation

State 00 contains generic vocabulary-basis communities including system/information terms, common verbs, punctuation and code/formatting structures. The four-family late organisation is not present there in the same form. The reconstructed late topology therefore cannot be reduced to the shared newline baseline.

11. Final interpretation

FINAL-POSITION CONDITIONING
          ↓
MIDDLE-LAYER DIVERGENCE
          ↓
LATE HIGHER-ORDER RECONVERGENCE

The stable object is not the literal ordering of the supplied nouns. What reconstitutes is a more abstract structural schema linking constraints, configurable structure, paths or trajectories, and deformation or adjustment.

Project-level conclusion. R018 supports the project hypothesis in a narrower and more defensible form: changes across transformer layers can reveal recoverable learned semantic organisation that survives substantial prompt-order perturbation at a higher level of abstraction. R018 does not show that exact training documents can be reconstructed, nor that one fixed topology is preserved unchanged through the network.

13. Limitations

  • One model was tested.
  • One three-concept semantic region was tested.
  • The perturbation was prompt order rather than broad contextual replacement.
  • Parent labels remain post-measurement semantic reconstructions.
  • Vocabulary projection contains lexical, formatting, multilingual and code structure that must not be mistaken for prompt-specific meaning.
  • Cross-model and large-scale replication remain separate questions.

14. Completion status

R018 is complete as an experimental run: the measurement is frozen and validated; the six permutations have been semantically reconstructed; the invariant parent map, relations, and measured semantic-network graph report have been recorded; excluded structures have been documented; and the project-level implication has been stated.

Further experiments may test generality, but they are not required to complete R018 itself.
