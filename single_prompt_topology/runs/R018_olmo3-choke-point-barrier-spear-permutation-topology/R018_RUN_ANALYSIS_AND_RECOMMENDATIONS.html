R018 — Semantic reconstruction and final analysis

OLMo 3 32B · six permutations · post-measurement reconstruction

Strongest supported result. The six input orders do not preserve one literal semantic map. They diverge into final-position-conditioned branches, reach maximum cross-order differentiation in the middle layers, then reconverge onto a shared late topology coupling constraint/requirement, structural configuration, dynamic path geometry, and collapse/adjustment.

1. Experimental basis

R018 measures all six permutations of choke point, collapsible barrier and spear. The six-prompt batch and its deterministic replay are exactly equal. Measurement contains 780 networks, 3,081,305 selected memberships, 30,813,050 directed 10-NN edges, 11,872 state-local communities and 1,950 same-state permutation comparisons.

This report begins after the semantic-free measurement boundary. Semantic labels below are interpretations of measured communities and relations.

At State 64 the relevant families are directly connected or fused in all six permutations. Representative positive-sector edge counts include ABC 408, ACB 326, BAC 501, BCA 502, CAB 338 and CBA 520.

At State 63 the families repeatedly connect or fuse. Representative connections include ABC C6–C12 (139 edges), ACB C9–C13 (63), BAC C6–C7 (215), BCA C0/C4 (509), CAB C9–C10 (156) and CBA C7–C10 (215).

Constraint / Requirement ↔ Collapse / Adjustment

9. State 00 control

State 00 is identical across all permutations and contains generic vocabulary-basis structure such as system/information, common verbs, punctuation and code/formatting communities. The same four-family organisation is not present there. The late result is therefore not merely the shared newline baseline.

The invariant is not the literal supplied nouns. The stable object is a structural/dynamic schema relating constraints, configurable structure, paths/trajectories and deformation/adjustment.

Project-level implication. R018 supports the hypothesis that lower-level representational topology can be strongly order-dependent while a higher-order semantic topology reconstitutes across the perturbation. This is evidence for recoverable learned semantic structure, not evidence for exact training documents or causal mechanisms.

11. Limitations

R018 tests one three-concept semantic region, one model and one perturbation type: order. Parent labels remain post-measurement interpretations. Cross-context, neighbouring-concept and cross-model stability are not established. Vocabulary projection also carries lexical, formatting, multilingual and code structure that must not be mistaken for prompt-specific semantics.
