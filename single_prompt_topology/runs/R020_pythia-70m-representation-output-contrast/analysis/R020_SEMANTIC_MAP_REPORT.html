Shuffled-label control and epistemic boundary

The same screen labels 1,865 original communities and 0 globally shuffled-label communities. The lexicon was developed after seeing original community examples: the contrast demonstrates sensitivity to meaningful labels, not a blinded causal validation or independent evidence of prompt-conditioned understanding.

Unresolved ≠ irrelevant; absent from this candidate screen ≠ absent from the internal state. The 6,944 records include all unlabelled community IDs. Raw 1.42m token memberships are not in the compact GitHub exports; this map uses representatives, extreme tokens, reported token edges and transitions.
