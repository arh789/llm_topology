# R010 Phase C — insights

## Status

**CANONICAL PHASE-C INSIGHTS REPORT**

Phase C compares the frozen Phase-B semantic trajectory with the pre-existing R008 measured topology.

## Core result

Semantic evolution and measured topology correspond, but only partially.

Three distinct change modes are present:

~~~text
1. GLOBAL TOPOLOGICAL RESET
   membership changes
   + edges change
   + communities reorganise
   + semantic architecture changes

2. COMMUNITY RE-PARTITIONING
   membership largely persists
   + edges largely persist
   + community organisation changes
   + semantic parent architecture changes

3. SEMANTIC ABSTRACTION WITH GEOMETRIC STABILITY
   membership largely persists
   + edges largely persist
   + communities may remain similar
   + higher-order semantic organisation changes
~~~

Therefore Phase-B semantic evolution cannot be reduced to token turnover or community turnover.

## Endpoint resets

### S00→S01

This is the strongest measured reset in the run:

- average membership Jaccard: **0.029**
- average edge Jaccard: **0.002**
- mean ARI: **0.255**

The input-embedding neighbourhood is almost completely replaced by the first contextual transformer state.

### S31→S32

This is the second-largest reset:

- average membership Jaccard: **0.210**
- average edge Jaccard: **0.059**
- mean ARI: **0.322**

The terminal workflow therefore coincides with a genuine representational reorganisation rather than a simple semantic relabelling.

## Early versus late transformer

Early contextual layers contain substantially more:

- membership turnover;
- edge turnover;
- community repartitioning.

Later layers become much more geometrically stable.

Yet Phase B continues to observe:

- semantic merges;
- splits;
- reappearances;
- broadening and narrowing;
- higher-order functional integration.

The trajectory is therefore:

~~~text
EARLY / MID
geometric search / contextual selection
        ↓
neighbourhood and communities still moving

LATE
semantic compression / relational reorganisation
        ↓
higher-order meaning changes over a stable substrate

FINAL
terminal representational reset
~~~

These are descriptive labels, not claims about a known internal causal algorithm.

## Semantic change over stable geometry

The strongest examples are:

### S21→S22

- positive membership Jaccard: **0.894**
- positive edge Jaccard: **0.761**

Yet Phase B identifies a major positive semantic merge.

### S26→S27

- positive membership Jaccard: **0.866**
- positive edge Jaccard: **0.709**

Yet the dominant positive parent expands to **72.1%** semantic-eligible coverage.

### S30→S31

Community assignment remains unusually stable while the positive architecture splits into analytical/evidential and professional/information-production structures.

These transitions imply that late semantic development increasingly concerns **relations among already-present components**, not wholesale replacement of those components.

## Negative-side asymmetry

The negative side converges earlier on:

- T-C — characterisation / regulation / adverse evaluation / controlled change;
- T-A — authority / territory / institutional-social order.

Exploratory correlations show that negative-side semantic restructuring tracks measured membership and edge disruption more closely than positive-side restructuring does.

The positive side is therefore more capable of higher-order semantic reorganisation over stable geometry.

## Strongest Phase-C conclusions

1. **Semantic evolution is real but not reducible to measured topology change.**
2. **S00→S01 and S31→S32 are genuine semantic and topological resets.**
3. **Early transformer development contains much more membership and edge turnover than late development.**
4. **Late positive semantic integration frequently occurs over highly stable measured neighbourhoods.**
5. **Community repartitioning can reveal semantic re-differentiation even when membership and edge similarity remain high.**
6. **Negative semantic restructuring tracks measured topology more closely than positive restructuring.**
7. **The persistent negative T-C control backbone around S09–S11 is supported by strong measured topology change.**
