# LLM Semantic Topology Research

This is the independent working repository for an experimental project
examining semantic conflict, language-model behaviour and internal
representation geometry.

## Current evidence state

The package contains a research design and one behavioural case mapping. It
does not contain experimental results, activation captures, model weights,
datasets or evidence that semantic conflict corresponds to geometric
curvature.

## Reading order

1. [`PROJECT_HANDOVER.md`](PROJECT_HANDOVER.md) — the governing research

2. [`ZOMBIE_CASE_STUDY.md`](ZOMBIE_CASE_STUDY.md) — how an existing

## First experiment: Pythia 410M prompt playground

[`pythia_410m_prompt_playground.ipynb`](pythia_410m_prompt_playground.ipynb)
loads the final `EleutherAI/pythia-410m` checkpoint and provides an editable
prompt cell that returns the generated continuation. It also records the seed,
sampling settings, token counts, latency and peak GPU memory.

This machine currently needs a Python and JupyterLab environment before the
notebook can be opened. On Windows:

1. Install Python 3.11 or later.
2. Create and activate a project environment:

   ```powershell
   py -3.12 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install --upgrade pip
   ```

3. Install a CUDA-enabled PyTorch build using the command generated by the
   [official PyTorch selector](https://pytorch.org/get-started/locally/).
4. Install the notebook dependencies and launch JupyterLab:

   ```powershell
   python -m pip install jupyterlab "transformers>=4.48" safetensors
   python -m jupyter lab
   ```

The first model-loading run downloads the checkpoint from Hugging Face. Pythia
410M is a base next-token model, not an instruction-tuned assistant, so the
notebook deliberately evaluates completions rather than chat behaviour.

The notebook verifies that `HF_HOME` is `D:\AI\cache\huggingface` and
`HF_HUB_CACHE` is `D:\AI\cache\huggingface\hub` before loading anything. It
stops before a download if the shared model-cache configuration is missing or
points elsewhere.

## Interpretation boundary

Keep these levels separate throughout analysis:

- observable model responses;
- researcher interpretations of those responses;
- model-generated explanations of its own behaviour;
- measured internal representations;
- causal conclusions supported by interventions.

Only the first three are present in the behavioural case. The proposed project
is intended to measure the fourth and test the fifth.
